# OpenCabinet for ChatGPT / OpenAI

Remote Streamable HTTP MCP integration (`https://opencabinetai.com/api/sales-mcp`) secured with OAuth 2.1 + PKCE and Dynamic Client Registration, powered by Cabinet-X.

## Capabilities

- **Cloud Layout Generation (`cabinetx_cloud_generate`)**: Create a new customer project from room measurements or an uploaded sketch, run the server-side cabinet layout solver, render an interactive 2D plan card, view a customer-facing retail quote estimate, and open directly in Cabinet-X 3D Canvas.
- **Cloud Design Editing (`cabinetx_mobile_design`)**: Inspect actual catalog options and apply verified finish, cabinet, and island edits in the cloud with revision & editor-lease protection.
- **Sales Context & Follow-ups (`cabinetx_sales_*`)**: Search projects, read published quotes and history, and save owner-requested follow-up records.

## Direct Connection (No Store Wait)

Add `https://opencabinetai.com/api/sales-mcp` in ChatGPT, Claude, Cursor, VS Code, or Gemini and sign in via OAuth.
